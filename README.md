# 🌸 Muvette - Premium Hair Care & Beauty Tools E-commerce

Una tienda online moderna y elegante para herramientas profesionales de cuidado del cabello y productos de belleza, construida con Next.js 16 y Tailwind CSS.

## 💫 Producto Destacado

**Muvette Air** - Secador de pelo profesional con tecnología iónica, diseño ergonómico ligero y detalles en rosa que combinan con la identidad de marca.

## 🎨 Paleta de Colores

- **Principal**: `#ffe6ef` - Rosa suave pastel
- **Blanco**: `#ffffff` - Fondo limpio
- **Acento**: `#ff69b4` - Rosa vibrante para CTAs y destacados
- **Texto**: `#1a1a1a` - Negro suave para contenido

## 🚀 Tecnologías

- **Framework**: Next.js 16.1.0 (App Router)
- **UI**: React 19.2.3
- **Estilos**: Tailwind CSS v4
- **Lenguaje**: TypeScript
- **Optimización de Imágenes**: Next.js Image Component

## 📁 Estructura del Proyecto

```
muvette/
├── app/
│   ├── components/
│   │   ├── Header.tsx          # Header con menú, búsqueda y carrito
│   │   └── ProductCard.tsx     # Tarjeta de producto con bundles
│   ├── globals.css             # Estilos globales y tema
│   ├── layout.tsx              # Layout raíz
│   └── page.tsx                # Página principal
├── public/
│   ├── logo.svg                                           # Logo de Muvette (llama)
│   └── Gemini_Generated_Image_bkzt7qbkzt7qbkzt.png       # Imagen del Muvette Air
└── package.json
```

## 🎯 Características

### Header
- Logo de marca personalizado
- Menú hamburguesa responsive
- Búsqueda de productos
- Carrito de compras con contador de items
- Banner promocional destacado

### Product Card
- Imagen de producto grande con fondo rosa
- Sistema de calificación con estrellas
- Precios con descuentos destacados
- Lista de beneficios del producto
- Opciones de bundles con precios especiales
- Botón de "Add to Cart" prominente

## 🛠️ Comandos

```bash
# Desarrollo
npm run dev

# Build para producción
npm run build

# Iniciar servidor de producción
npm start

# Linting
npm run lint
```

## 🌐 Servidor de Desarrollo

El proyecto está corriendo en:
